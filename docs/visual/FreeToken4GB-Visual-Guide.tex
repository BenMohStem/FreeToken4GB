\section{The budget problem: why 4\,GiB was ``impossible''}
%=====================================================================

\medskip

CUDA-graph scratch. This fork: embedding table (\MiB{970}) moved to CPU and KV
halved to FP8 fits with \textbf{717.8\,MiB to spare} after full init.
